# Your Energy

Fitness exercises catalog: browse categories by muscles, body parts or
equipment, search exercises, see details and keep favorites. Built with Vite and
vanilla JavaScript on the
[Your Energy API](https://your-energy.b.goit.study/api-docs).

Live: https://s-voloshynenko.github.io/project-SoloVolo/

## Development

```bash
npm install
npm run dev
npm run build
```
